# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We are happy to receive contributions from everyone. Please follow the guidelines below so that changes can be reviewed and merged smoothly.

## Code of Conduct

By participating in this project, you agree to follow the CODE_OF_CONDUCT. Please be respectful and constructive in all interactions.

## How to Contribute

1. Check the existing issues before opening a new one.
2. Fork the repository.
3. Create a new branch for your change.
4. Make your changes and test them locally.
5. Commit your changes with a clear message.
6. Push the branch to your fork.
7. Open a pull request describing your change.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- The operating system and Bash version, if relevant.
- Any error messages or terminal output.

## Suggesting Enhancements

Enhancement ideas are welcome. Please describe the proposed improvement, why it would be useful, and any examples of how it should work.

## Documentation Improvements

Documentation fixes and improvements are appreciated. This includes corrections to README.md, clearer usage examples, and additional explanations of the simple interest formula.

## Pull Request Guidelines

- Keep pull requests focused on a single change.
- Include a clear title and description.
- Update documentation when behavior changes.
- Make sure the script still runs correctly.
- Be responsive to review comments.

## Coding Style

For Bash changes:

- Use a shebang line.
- Quote variables where appropriate.
- Validate user input.
- Keep the script readable and well commented.
- Use clear error messages.
